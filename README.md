## ✨ Features

- ✅ **Task Management** — Create, complete, and delete tasks effortlessly.
- 📊 **Progress Tracking** — Monitor your productivity with real-time statistics.
- 🌙 **Modern Dark UI** — A clean and elegant interface.
- 💾 **Local Storage** — Your tasks stay saved even after refreshing the page.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile.
- ⚡ **Fast & Lightweight** — No frameworks or external dependencies required.

| Technology | Purpose |

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/nexora-dashboard.git
```

**2. Open the project**

```bash
cd nexora-dashboard
```

**3. Launch the application**

Open `index.html` in your favorite browser.

No installation, build tools, or server required.
