# Nexora — Personal Dashboard ✦

A sleek, responsive task management dashboard built with vanilla HTML, CSS and JavaScript.

## Features
- Add, complete and delete tasks
- Filter by all, active and completed tasks
- Live stats and completion progress bar
- LocalStorage persistence across refreshes
- Responsive dark-mode interface
- No dependencies or backend required

## Run locally
1. Clone or download the repository.
2. Open `index.html` in your browser.

## Tech stack
HTML5 · CSS3 · JavaScript (ES6+)
